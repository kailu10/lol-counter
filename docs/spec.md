# 仕様書

## 概要

League of Legends のチャンピオンごとのカウンターピックを確認できるウェブツール。国内の友人間での利用を前提とし、全文日本語で提供する。

---

## 対象ユーザー・前提

| 項目 | 内容 |
|------|------|
| 対象ユーザー | 国内の友人間（限定利用） |
| 言語 | 日本語（UI全体） |
| ランク帯 | エメラルド以下（Iron / Bronze / Silver / Gold / Platinum / Emerald） |

---

## 機能要件

### チャンピオン検索

- テキスト入力によるインクリメンタルサーチ（オートコンプリート表示）
- 入力は日本語・英語どちらでもマッチする（例：「ダリウス」「Darius」「darius」）
- ロール別グリッド一覧からの選択（トグルで表示／非表示）
- チャンピオン一覧はロールで絞り込み可能（TOP / JG / MID / ADC / SUP）
- チャンピオンアイコンは Riot Data Dragon CDN から取得

### ロール選択

- TOP / JG / MID / ADC / SUP の5択
- チャンピオン検索と同一画面で選択する
- 検索実行時に選択中のロールも含めてURLに反映される

### カウンター結果表示

- 最大Top10件を表示
- 各エントリに表示する情報：

| 項目 | 説明 |
|------|------|
| 順位 | 1〜10（1〜3位はゴールド強調） |
| チャンピオンアイコン | Data Dragon から取得 |
| チャンピオン名（日本語） | Data Dragon ja_JP ロケールから取得 |
| 勝率 | 複数サイトの加重平均（小数第1位まで） |
| 難易度 | op.gg から取得（易しい / 普通 / 難しい） |
| 信頼スコア | データ取得できたサイト数を★で表示（最大★★★） |

- 現在のパッチバージョンを結果パネルに表示
- データが1サイトしか取れなかった場合でも部分表示する

### URL共有

- 検索結果は `/counter/[championId]/[role]` の形式でURLに反映される
- URLをそのままコピーして友人に共有できる
- ブラウザの戻るボタンで検索画面に戻れる

---

## データ仕様

### データソース

| サイト | 用途 | ランク帯パラメーター |
|--------|------|------------------|
| op.gg | 勝率・難易度 | `tier=emerald` |
| lolalytics | 勝率 | `tier=emerald_plus` |
| lol.ps | 勝率 | `tier=6`（Emerald相当） |

### チャンピオンマスターデータ

Riot Data Dragon の `ja_JP` ロケールから取得する。パッチバージョンも同APIから自動取得する。

```
https://ddragon.leagueoflegends.com/api/versions.json
https://ddragon.leagueoflegends.com/cdn/{version}/data/ja_JP/champion.json
```

### 集計ロジック

1. 3サイトから並列にスクレイピング（各タイムアウト8秒）
2. チャンピオンIDを正規化（小文字・英数字のみ）して名寄せ
3. 勝率は取得できたサイトの単純平均
4. ソート順：**サイト一致数（降順）→ 勝率（降順）**
5. 上位10件を返す

### キャッシュ

| 項目 | 内容 |
|------|------|
| 方式 | サーバーサイド インメモリキャッシュ |
| TTL | 4時間 |
| キー | `{championId}:{role}`（小文字） |
| 対象 | カウンター集計結果（`CounterResult`） |

> Vercel はサーバーレスのため、デプロイをまたいでキャッシュはリセットされる。

---

## 非機能要件

| 項目 | 内容 |
|------|------|
| レスポンシブ | スマートフォン・PC両対応。モバイルでは難易度・信頼スコア列を非表示 |
| 表示言語 | 日本語 |
| デザインテーマ | ダーク（濃紺背景・ゴールドアクセント・青紫インタラクティブ） |

---

## 制約・注意事項

- 外部サイトのスクレイピングを利用しているため、サイト側の構造変更でデータ取得が失敗する場合がある
- 利用規約上グレーな取得方法を含むため、公開範囲は限定利用にとどめる
- Vercel 無料枠のサーバーレス関数タイムアウト（最大10秒）の制約内で3サイトの並列取得を行う
